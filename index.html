Lontar for Linux

These are the APT and DNF repositories Lontar updates from. Installing the .deb or .rpm from the latest release adds them for you, so new versions then arrive with your system's updates.

Debian and Ubuntu

sudo curl -fsSLo /usr/share/keyrings/lontar.asc https://aaripurna.github.io/lontar/lontar.asc
sudo curl -fsSLo /etc/apt/sources.list.d/lontar.sources https://aaripurna.github.io/lontar/lontar.sources
sudo apt update && sudo apt install lontar

Fedora

sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-lontar https://aaripurna.github.io/lontar/lontar.asc
sudo curl -fsSLo /etc/yum.repos.d/lontar.repo https://aaripurna.github.io/lontar/lontar.repo
sudo dnf install lontar
